  `[tool.ruff.lint] select = ["E", "F", "W", "I", "UP", "B", "NPY"]`.

## 4. `src/uavapf/paths.py`

```python
ENV_VAR: str = "UAVAPF_RESULTS"


def results_root() -> pathlib.Path: ...
def ensure_dir(path: pathlib.Path) -> pathlib.Path: ...
```

`results_root()`
- If `UAVAPF_RESULTS` is set and not empty/whitespace: return that path with
  `~` expanded, made absolute (relative values resolve against the current
  working directory).
- Otherwise: return `Path.cwd() / "results"` (absolute).
- Must **not** create the directory. Reads the environment at call time
  (no caching at import).

`ensure_dir(path)`
- Creates `path` with parents if missing (`exist_ok=True`), returns `path`.

## 5. CI (`.github/workflows/ci.yml`)
- Triggers: `push` (all branches) and `pull_request`.
- Matrix: `os: [windows-latest, ubuntu-latest]`, `fail-fast: false`.
- Steps: checkout → `astral-sh/setup-uv` (with caching) → `uv sync --locked`
  → `uv run ruff check .` → `uv run ruff format --check .` → `uv run pytest -q`.
- Python version comes from `.python-version`.

4. PR diff contains no files outside the list in §2 (plus `uv.lock`).
